# Bookmarks and Tooltips Notes

## Overview
The report includes interactive usability features to improve navigation, explain metrics, and keep page layouts clean.

## Bookmarks
Bookmarks are used to support user-friendly interactions such as:

- filter pane show / hide
- guided report navigation
- reset-style interactions
- clean default page views

### Filter Pane Bookmark Design
A dedicated filter pane is implemented using bookmarks so that:

- the page remains visually clean by default
- users can expand filters when needed
- the report supports guided interaction without occupying constant report space

## Tooltips
Tooltips are added where they improve understanding without increasing visual clutter.

### Tooltip Usage
Tooltips are used for:

- KPI descriptions
- metric guidance
- hover-based clarification on selected visuals
- additional context where page space is limited

### KPI Tooltips
KPI tooltips are specifically used so users can quickly understand:

- what a KPI means
- how it should be interpreted
- the business context behind the value

## Info / Guide Pages
The report also includes dedicated information pages to explain:

- how to use the report
- how page interactions work
- how slicers and filters affect visuals
- how reset and navigation options work
- what the Last Refresh section indicates

## Last Refresh Status
A visible **Last Refresh On** element is included in the report so users can confirm the latest available refresh timestamp.

## Design Goal
The goal of using bookmarks, tooltips, and info pages is to improve usability while keeping the report structured, clean, and easy to interpret.
